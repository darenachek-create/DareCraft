# DareCraft — сайт от DARENACHEK studio

Готовый шаблон сайта для проекта **DareCraft**, подготовленный для публикации на GitHub Pages.

## Что уже реализовано
- **Адаптивная шапка и мобильное меню** с подсветкой текущего раздела при прокрутке.
- **Hero-блок** со статусом разработки, бейджами проекта и быстрыми кнопками перехода.
- **Раздел «Об игре»** со структурированным списком механик и блоком про будущие структуры.
- **Раздел «Возможности»** с карточками ключевых особенностей.
- **Галерея с фильтрами и просмотрщиком** (переключение стрелками на экране и клавиатурой `←` / `→`, закрытие по `Esc`).
- **Раздел скачивания** с подсказкой по распаковке архива `assets/downloads/DareCraft.zip`.

## Куда положить свои файлы
1. Сборку игры положите в `assets/downloads/DareCraft.zip` (сейчас там лежит заглушка `README.txt` внутри примера).
2. Обложку раздела «Об игре» положите в `assets/studio-bg.png`.
3. Скриншоты игры положите в `assets/gallery/` и при необходимости обновите массив `GALLERY_ITEMS` в `script.js`.
