# DareCraft — обновлённый сайт от DARENACHEK studio

## Что нового в этой сборке
1. **Верхний индикатор прогресса прокрутки** (`scrollProgress`) с красным акцентом.
2. **Живой фон в Hero-блоке** с лёгким параллаксом от мыши и ручным переключателем сцен (**«Закат и стройка»** / **«Ночная битва»**) для файлов `фон1` и `фон2`.
3. **Плавное появление секций при прокрутке** (`IntersectionObserver`).
4. **Раздел «Обновления DareCraft» (`#updates`)** с карточками актуальной сборки `v0.1` и планов `v0.2`.
5. **Обновлённый блок скачивания и поддержки (`#download`)** с карточкой релиза и кнопкой копирования шаблона баг-репорта.
6. **Собственный `favicon.svg`** для вкладки браузера.

## Куда положить свои файлы
- Ваши скриншоты **`фон1.png`** и **`фон2.png`** положите в папку `assets/` (или рядом с `index.html`).
- Актуальную сборку игры положите в `assets/downloads/DareCraft.zip`.
- Обложку раздела «Об игре» положите в `assets/studio-bg.png`.
